# Laravel Showcase Demo

A personal full-stack project built to showcase backend developer capabilities, software architecture, and modern web application patterns using Laravel.

## 🚀 Key Features & Progress
* **Authentication & User Management:** Custom auth flow and user profile structure.
* **Photo & Feed Module:** Photo upload pipeline with relational data management.
* **Interactive Features:** Likes, comments, and engagement tracking.
* **Database & Infrastructure:** Powered by MariaDB, optimized via Docker/OrbStack.

## 🛠️ Tech Stack
* **Framework:** Laravel (PHP)
* **Database:** MariaDB
* **Environment:** Docker / OrbStack
